# Sudoku — C11 engine (v0.1.0 experimental build recovery)

This repository is the production-development home for the original C Sudoku exercise. **v0.1.0 is a build-recovery milestone, not a production-ready solver.** The historical in-memory single-puzzle demo has been restored and made safer; it has not yet been validated for arbitrary puzzles.

## Requirements

- CMake 3.16 or later
- A C11-capable compiler: GCC, Clang, or MSVC (the latter is not verified yet)
- Optional: Ninja for faster builds

## Build and run

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
./build/sudoku --help
./build/sudoku --version
./build/sudoku --demo
```

On Windows, use `build\\Release\\sudoku.exe` with a multi-configuration generator or the binary path generated by your CMake toolchain.

To use GCC/Clang sanitizers on a supported non-Windows host:

```sh
cmake -S . -B build-asan -DCMAKE_BUILD_TYPE=Debug -DSUDOKU_ENABLE_SANITIZERS=ON
cmake --build build-asan
ctest --test-dir build-asan --output-on-failure
```

The three CTest cases are **smoke tests**, not a correctness proof: `--help`, `--version`, and `--demo`. The demo prints a hardcoded puzzle before and after the experimental historical solver. The demo is also the default if no arguments are supplied. Unrecognized arguments cause a nonzero exit. Do not use this release to validate externally supplied Sudoku puzzles.

## v0.1.0 changes

- Restored missing `sudoku.h` declarations and source types.
- Fixed initial clue/candidate counting and row-single indexing bugs.
- Added bounded example solver loop, return values, and input index checks in update functions.
- Added allocation failure cleanup and destruction of puzzle/box/square memory.
- Standardized CMake on C11 with compiler warnings, CTest and opt-in sanitizers.
- Added lightweight `--help`, `--version` and `--demo` command-line options.
- Tested local GCC 14.2 Debug + ASan/UBSan and Clang 17 Release (see [verification report](docs/VERIFICATION_v0.1.0.md)).
